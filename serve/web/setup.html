Every model you install from this page goes there (llama.cpp models in its llama subfolder). Strata's own model files already in another folder on the same drive are moved there by its install; llama.cpp models are not moved.

Models

The chat page belongs to the running model (http://127.0.0.1:8080/ by default): start a model below and its chat opens in a new tab when it is ready.

A model is running (this page is part of it). To start another one, close this model's window first; an install can run beside it, but it takes the network, the disk and the CPU while the model answers.

Strata runs one model, Qwen3.8-Flash-Next (125B parameters, mixture of experts), in several versions and sizes. Which size fits depends mostly on your RAM; a bigger graphics card makes it faster.

Any GGUF model from ModelScope or Hugging Face runs with llama.cpp: Qwen, Gemma, GLM, gpt-oss, DeepSeek and more. The layers and experts that fit in VRAM go there, the rest stays in RAM.
